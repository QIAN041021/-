# 生活小助手（荔枝随心记）小程序

> 一款面向个人与家庭的**轻量化生活管理微信小程序**。以可自定义的首页仪表盘为核心，一站式覆盖待办打卡、记账理财、菜谱食材、物资进度、快递取件、家庭用药与健康档案等日常场景。支持本地账号与微信一键登录，主题与字体全局个性化。

## 一、小程序简介

- **定位**：个人 / 家庭日常事务的"一站式轻量管理工具"，替代在多个 App 间来回切换。
- **核心载体**：高度可自定义的首页仪表盘 —— 用户可拖拽排序、隐藏、新建模块，把最关心的生活指数放在首屏。
- **适用人群**：希望用一个小程序管理收支、食材、物资、快递、用药的学生 / 上班族 / 家庭用户。

## 二、功能简介

> 底部 Tab 固定 5 个：首页 / 记账 / 菜谱 / 进度条 / 取件码；登录、设置、用药为独立页。
> （注：Tab 名"进度条"对应代码页 `supply`）

| 页面 | 核心功能 |
|------|----------|
| 首页 index | 可拖拽自定义仪表盘，聚合待办/打卡/任务/数值/生活记录等模块；板块可排序、重命名、隐藏、新建 |
| 登录 login | 账号密码注册/登录 + 微信一键登录；游客缓存数据可合并进正式账号 |
| 记账 account | 个人/家庭合并余额、收支统计、每日记账、刚需/愿望清单自动记账、分类环形图 |
| 菜谱 recipe | 食材库分类管理、家常菜谱（自动判断"可做/缺料"）、做法详情 |
| 进度条 supply | 以进度条可视化各类物资剩余量，分类与物品支持增删改 |
| 取件码 pickup | 按驿站分类管理取件码，支持批量添加、勾选"已取件" |
| 设置 settings | 页面管理、马卡龙色调调整、字体大小/字重、意见反馈 |
| 用药 medication | 家庭成员健康档案、家用药物记录（图片/保质期/剩余数量） |

**全局通用能力**：侧边栏抽屉导航、主题与字体全局实时生效、本地存储 + 云端同步。

## 三、技术亮点

- **自定义导航体系**：自实现 `custom-tab-bar` 底部导航与 `components/drawer` 侧边栏抽屉，导航与业务解耦、体验统一。
- **微信云开发**：云函数 `getOpenid` 获取身份、`taskReminder` 触发订阅消息到期提醒，免自建后端。
- **双登录与数据合并**：账号密码 + 微信授权双通道；游客本地缓存可在登录后合并进正式账号。
- **可配置首页引擎**：5 类自定义模块（待办/打卡/任务/数值记录/生活记录）支持拖拽排序与持久化。
- **全局主题与字体引擎**：色调色板 + 字号/字重调节，所有页面实时生效。
- **原生轻量技术栈**：微信小程序原生框架（WXML/WXSS/JS），无第三方框架依赖，包体小、易维护。
