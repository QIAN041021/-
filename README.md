# 微信小程序（荔枝随心记）
这是一款生活类小程序的功能梳理具体内容如下：
一、主页面
设有账户板块，支持上传头像、编辑个人资料，现存优化点：需开放游客浏览权限，无需登录即可查看功能；账户旁设置页仅支持局部色调微调，需改为整体色调调整，意见反馈可同步至后台。页面内置今日生活指数区，支持自主新建自定义卡片，涵盖今日待办、每日打卡、近期任务、体重记录四类记录功能；

二、记账页面
包含余额、支出统计、AI辅助、记账记录板块，

三、菜谱页面
用于自建菜谱，可上传菜品实拍图、登记食材与烹饪步骤；

四、进度条功能
支持自定义任务完成度、物品消耗比例进度条；规划新增快递管理页面，按站点分类存放取件码

五、药物备忘录
可创建多个人物健康档案，记录姓名、年龄、病史、药物过敏等信息，支持快速切换档案；药品记录支持上传药品照片，自定义备注药品名称、功效用途与药品分类。
