# 生活小助手 - 微信小程序

基于 HTML 原型改造的完整微信小程序，保留了原有的粉色温暖主题风格，新增了用户注册登录与数据持久化功能。

## 快速开始

### 1. 下载微信开发者工具

前往 [微信官方文档](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html) 下载并安装微信开发者工具。

### 2. 导入项目

1. 打开微信开发者工具，选择「导入项目」
2. 项目目录选择本文件夹（`生活小助手小程序`）
3. AppID 处：
   - 如果已有小程序 AppID，填入你的 AppID
   - 如果没有，可选择「测试号」体验（部分功能如真机预览受限）
4. 点击导入

### 3. 运行

导入后即可在模拟器中看到小程序运行。首次打开会进入登录页，可：
- **注册新账号**：输入账号（≥6位）和密码（≥6位），注册后自动登录
- **微信一键登录**：使用本地匿名身份快速进入（测试用，数据保存在本设备）
- 已登录用户再次打开会自动跳转到首页

## 功能一览

| 页面 | 功能 |
|------|------|
| 登录页 | 账号注册 / 登录 / 微信一键登录 |
| 首页 | 今日生活指数：待办事项、每日打卡、近期任务、体重记录 |
| 记账 | 余额管理、收支统计（今日/本周/本月）、消费列表、刚需清单、愿望清单、消费分类环形图 |
| 菜谱 | 我的食材管理（分类标签）、家常菜谱（可做判断、图片、步骤）、食材关联推荐 |
| 用品 | 日常用品剩余量管理（可爱彩色方块、进度条、快速修改比例） |

## 数据持久化

- **本地存储模式**：账号和生活数据使用 `wx.setStorageSync` 按用户隔离保存，长期保留在本设备。
- **建议云端提交**：设置页的“给开发者的建议”会先保存本机；配置云环境后，会额外提交到云数据库 `feedback` 集合，开发者可在云开发控制台查看。
- **全量云同步**：账号、个人资料、记账、菜谱、进度条等数据目前仍是本地保存，暂未迁移到云端。

## 配置建议云端提交

1. 在微信开发者工具中点击「云开发」，创建云环境并复制环境 ID。
2. 打开 `utils/cloud.js`，将 `CLOUD_ENV` 改成真实环境 ID。
3. 在云开发控制台创建数据库集合 `feedback`。
4. 将集合权限设置为“所有用户可写，仅创建者可读”或按你的管理方式配置。
5. 重新编译小程序，在设置页提交建议后，到 `feedback` 集合查看记录。

未配置环境 ID 时，建议仍会保存到本机，并提示“已保存到本机，云环境未配置”。云端提交失败时也会保留本地记录。

## 任务到期微信提醒（订阅消息）

首页「近期任务」板块中，每个任务右侧新增铃铛按钮：点击即可**订阅该任务的到期提醒**。到了任务截止日当天，微信会通过「服务通知」自动推送一条提醒（一次性订阅，每条任务推送 1 次）。

### 配置步骤

1. **申请订阅消息模板**
   - 登录「微信公众平台 → 订阅消息 → 我的模板」，申请一个「待办 / 日程提醒」类模板。
   - 记下模板 ID，并确认模板的关键词字段（常见为：任务名称 `thing1`、截止时间 `time2`、备注 `thing3`）。
2. **填入模板 ID**
   - 打开 `utils/subscribe.js`，把模板 ID 填到 `TASK_REMIND_TMPL_ID`（或用 `subscribe.setTemplateId(...)` 运行时设置）。
   - 云函数 `cloudfunctions/taskReminder/index.js` 顶部的 `TEMPLATE_ID` 也要填**同一个**模板 ID；若你的关键词字段名不同，同步修改 `buildData()` 中的 `thing1/time2/thing3`。
3. **部署云函数**
   - 在开发者工具中，分别右键 `cloudfunctions/getOpenid` 和 `cloudfunctions/taskReminder`，选择「上传并部署：云端安装依赖」。
   - `taskReminder` 已配置定时器（默认每 5 分钟扫描一次），自动在到期当天下发提醒。
4. **云环境**
   - 提醒推送依赖已在 `utils/cloud.js` 配置的云环境（见上一节）。未配置云环境时，铃铛点击会提示「需开启云开发后使用提醒」，不会报错。

### 工作机制

- 用户点击铃铛（手势触发）→ 客户端拉取 `openid` 并调用 `wx.requestSubscribeMessage` 请求授权；
- 授权成功后，任务记录写入 `remind: true`、`openid`、清空 `reminded`；
- 云函数定时扫描 `lifeIndex` 集合，对「已订阅 + 未完成 + 到期当天 + 未推送过」的任务调用 `subscribeMessage.send`，成功后置 `reminded: true` 防重复；
- 用户再次点击铃铛可关闭提醒（清除标记）。

## 字体大小与粗细

设置页新增「字体」标签页，可全局调整 App 文字：

- **字号**：4 档滑块（小 0.85 / 标准 1.0 / 大 1.15 / 特大 1.3），通过 CSS 变量 `--app-font-scale` 作用到所有页面与弹窗，每个 `font-size` 已改写为 `calc(Nrpx * var(--app-font-scale, 1))`，标准档与改造前完全一致、不会回归。
- **字重**：常规 400 / 中粗 600 / 加粗 700，通过 `--app-font-weight` 由 `.screen` 级联到全站正文。
- 设置实时保存在 `store.settings`，并通过 `theme.applyFont(page)` 在每个页面 `onShow` 注入 `.screen` 与 `.modal-overlay` 的内联 style；旧账号缺失该字段时自动补默认，不崩溃。

## 弹窗按钮醒目化

所有弹窗的「取消 / 完成 / 确认 / 保存」按钮统一增强：加粗（700）、加大内边距、清晰边框与投影；确认类按钮使用主题主色填充，关闭类按钮为描边样式，触感与可读性明显提升。

## 全量升级为云开发（后续方向）

如果需要账号、个人资料、记账、菜谱、进度条等数据跨设备同步，还需要进一步把 `utils/store.js` 迁移到云数据库，并通过云函数用真实 `openid` 替代当前本地匿名身份。

## 技术要点

- **自定义 TabBar**：使用 `"custom": true` 实现胶囊式底部导航，配合 SVG 图标
- **SVG 图标**：小程序不支持内联 SVG，通过 `data:image/svg+xml` URI 编码实现
- **Canvas 2D**：记账页消费统计使用 Canvas 2D API 绘制环形图
- **按用户隔离**：每个用户的数据存储在独立的 storage key 中（`lifeapp_user_<userId>`）
- **会话恢复**：登录状态通过 `wx.setStorageSync('lifeapp_session', ...)` 保存，重启自动恢复

## 注意事项

- 当前密码使用本地哈希（非加密级别），生产环境应在服务端使用 bcrypt 等安全哈希
- 微信一键登录目前生成本地匿名身份，生产环境需通过云函数换取真实 openid
- 图片上传使用 `wx.chooseMedia`，临时路径在重启后失效，生产环境需上传到云存储
